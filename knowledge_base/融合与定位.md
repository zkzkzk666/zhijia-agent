# 融合与定位

## 多传感器融合

- **松耦合**：各传感器独立输出目标/轨迹，再由融合模块做关联与状态估计；实现简单、易维护，但信息利用不充分。
- **紧耦合**：直接在原始量测（如 LiDAR 点、GNSS 伪距）层面联合估计；精度更高，但计算与实现复杂。
- **融合核心工具**：卡尔曼滤波（KF/EKF/UKF）、粒子滤波；目标关联常用匈牙利算法 + 马氏距离门控。
- **状态量**：常见为 3D 位置/速度/朝向 + 尺寸（LWH）+ 类别 + 置信度。

## 定位方案

- **GNSS/RTK**：RTK 可获得厘米级，依赖基站/网络差分；遮挡环境易丢锁，需其他源补偿。
- **IMU**：高频航迹推算，短时可靠、长时漂移，需融合修正。
- **里程计**：轮速/视觉里程计（VO）/激光里程计（LO），用于 GNSS 失效时的连续定位。
- **高精地图匹配**：横向/纵向地图特征（车道线、路沿、标志）匹配，用于结构化道路。
- **SLAM**：在建图与定位同时进行的场景（无图区域、泊车场）。

## 组合定位（典型状态机）

1. RTK-GNSS + 地图匹配 + IMU 紧耦合 → 高精度；
2. GNSS 降级（RTK 丢失）→ 伪距/双频定位 + 地图匹配；
3. GNSS 完全失效 → VO/LO + IMU 航迹推算；
4. 置信度低于阈值 → 提示接管或降级到低速/靠边。

## 高精地图（HD Map）

- 分层：道路拓扑层、车道几何层、路面标记层、定位特征层。
- 更新：众包差分更新、路测数据回注、局部刷新（云 + OTA）。
- 合规：国内高精地图需资质许可与地图合规审查，采集数据需脱敏。

## 失效与安全

- 定位失效等级划分，并绑定 ODD：定位置信度不足时应触发降级或退出。
- 关键指标：横向/纵向定位误差（如 ≤10cm）、航向误差、定位可用率、丢锁时长。
- 失效演示与回放：记录原始 GNSS/IMU/里程计数据与融合输出，便于问题复现。
