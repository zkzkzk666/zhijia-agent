# 法规与网络安全

## 中国智能网联汽车主要法规脉络

- **准入管理**：《智能网联汽车准入和上路通行试点》——L3/L4 车型需申请准入试点，具备安全设计、测试验证、数据记录与监管能力。
- **数据安全**：《汽车数据安全管理若干规定（试行）》——重要数据（高精地图测绘、人车流轨迹）需脱敏、境内存储、风险评估。
- **个人信息**：《个人信息保护法》《数据安全法》——车内外个人信息的收集需告知同意、最小化、脱敏。
- **测绘合规**：高精地图采集需导航电子地图制作资质，测绘数据不得出境。
- **驾驶员监控**：L3 需对驾驶员状态监控（DMS）并支持接管，定义接管提示与风险最小化操纵。

## 功能安全与网络安全协同

- ISO 26262 管「失效」，ISO 21434 管「被攻击」——两者共享威胁/危害分析、需求追溯、验证活动。
- 共同点：TARA（威胁分析与风险评估）与 HARA 的 E/C/S 定级可互相参考。

## ISO 21434 网络安全工程要点

- **TARA**：识别资产、威胁、攻击路径，评估风险等级，确定安全目标。
- 常用控制：安全启动（Secure Boot）、报文认证（SecOC/HSM）、密钥管理与远程证明、安全 OTA 签名、安全日志与审计、异常检测（IDS）。
- **供应链**：供应商的网络安全能力评估与责任划分；SBOM（软件物料清单）管理。

## 智驾企业落地清单

1. 数据分类分级清单 + 访问控制 + 审计。
2. 高精地图采集、处理、存储的资质与合规流程。
3. L3 准入要求的整车级安全验证文件（功能安全 + SOTIF + 网络安全 + 数据记录）。
4. 事件/事故数据记录仪（EDR/智能网联数据记录）满足取证要求。
5. 建立「安全事件 → 原因分析 → 召回/OTA → 监管沟通」闭环流程。

## 国际趋势

- 欧盟 UN-R157（ALKS 车道保持系统）、UN-R155/156（网络安全管理体系与软件更新管理体系）——出口车型需满足。
- 欧洲数据（GDPR）与国内个人信息保护法对数据出境的「充分性」评估要求。
