# 规划与控制

## 整体分层

- **感知** → **预测**（目标未来轨迹）→ **决策**（行为选择：跟车/变道/超车/靠边/接管）→ **规划**（轨迹/速度）→ **控制**（横向/纵向执行）。

## 行为决策

- 规则式：有限状态机（FSM），状态如巡航/跟车/变道/让行/停车，配合条件转移。
- 学习式：基于强化学习/模仿学习的决策，需严格约束与安全兜底（监护层）。
- 责任与边界：任何学习式决策都应有规则兜底与最小风险操纵（MRC）。

## 轨迹规划

- **Frenet 坐标系**：s（纵向里程）与 d（横向偏移），把规划拆成纵向/横向独立求解，常见于 Openplanner/EM Planner。
- **EM Planner（百度）**：动态规划粗选 + 二次规划精化，处理变道与决策。
- **基于优化**：MPC、梯度优化，直接对轨迹多项式/贝塞尔参数优化，满足动力学约束。
- **采样/搜索**：RRT、Lattice Planner（网格采样状态 → 轨迹族 → 代价评估）。

## 功能逻辑（AEB / ACC / LKA）

- **AEB**：前碰撞时间（TTC）< 阈值 → 预警 → 部分制动 → 全力制动；需考虑不同车速段的减速度与误触发抑制。
- **ACC**：纵向跟车，PID/MPC 控制加速度，约束：最大加减速度、车距保持、前方切入/切出目标的平滑切换。
- **LKA/LDW**：横向纠偏，基于车道中心偏移与曲率，控制转角；需明确驾驶员意图优先级（力矩/转向角门限）。

## 控制算法

- **PID**：简单、可调，适合低速与稳态；需防积分饱和与微分噪声。
- **MPC**：显式处理约束（加速度/转角/误差界），适合高速与强约束场景；实时性需工程优化。
- 纵向控制量：目标加速度/减速度；横向控制量：方向盘转角或前轮转角。

## 接管、降级与退出

- 完整触发条件：置信度过低、超 ODD、功能失效、驾驶员疲劳等。
- 响应策略分级：声音/视觉/振动提醒 → 限速 → 靠边停车 → 完全退出并交还控制。
- 接管时间内驾驶员状态确认：DMS/方向盘握持/制动踏板信号综合判断。

## 标定与调参要点

- 参数含义要明确（如舒适减速度、最小车距、介入时延），调整方向要有依据。
- 所有标定参数应版本化管理，上线前进行场景回归测试。
