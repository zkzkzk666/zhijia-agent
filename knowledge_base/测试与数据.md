# 测试与数据

## 测试金字塔（智驾视角）

1. **单元/模块测试**：感知、规划、控制各算法的单元验证（CI 内跑）。
2. **SIL（软件在环）**：算法 + 仿真环境闭环，批量跑场景库。
3. **HIL（硬件在环）**：真实域控 + 仿真传感器激励，验证时序与接口。
4. **整车在环 / 路测**：封闭场地 + 公开道路，验证整车级行为。
5. **大规模数据回放**：用采集的真实场景数据离线回归算法版本。

## 场景库设计

- **分类**：功能场景（normal）、边界场景（边界条件）、失效场景（传感器/系统失效）、误用场景（驾驶员误用）。
- **要素**：道路拓扑、交通参与者（类型/行为/意图）、天气光照、传感器配置、初始状态。
- **来源**：法规标准（如 C-NCAP/E-NCAP）、实车数据挖掘（罕见场景聚类）、随机/对抗生成。
- **度量**：场景覆盖率、按 ODD 维度的分布覆盖。

## 路测与数据闭环

- **采集**：多传感器同步采集 + 真值（RTK/人工标注）+ 标注驾驶行为。
- **数据平台**：脱敏（人脸/车牌/定位）+ 回注 + 自动标注 + 质检。
- **闭环**：路测发现问题 → 提取场景 → 仿真复现 → 算法迭代 → 回归验证。
- **指标**：接管率（次/千公里）、MPI（接管间隔里程）、功能误触发率、OOS（超出运行域未及时处理）次数。

## 数据脱敏

- 对象：人脸、车牌、位置轨迹、用户隐私音频。
- 方法：检测 + 打码/模糊/替换、轨迹扰动（半径/时段偏移）、字段级加密。
- 合规：数据跨境、数据分级、个人信息保护法要求，脱敏后仍需授权与审计。

## 问题复现与定位

- 完整记录：时间戳、传感器原始流、感知/融合/规划中间量、控制输出、日志。
- 使用数据回放工具逐模块对齐时间轴，比较新老版本差异。
- 输出：问题报告（现象、复现条件、影响等级、根因假设、验证结果）。

## 测试报告

- 结论式：目标、方法、样本量、通过标准、结论、风险项。
- 数据支撑：统计表 + 典型案例截图/回放链接。
